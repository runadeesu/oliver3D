# Oliver_Cowboy_Tears_A_Pose — 指と口が動くリグ付きモデル

カウボーイハット / 青いフリンジジャケット / 丸サングラス / ヤギひげ。作り直された Meshy FBX(`Cowboy.fbx`。https://gofile.io/d/tVUQudhH)を、元の見た目(形状・色・UV・テクスチャ)を保ったまま、指と口が動くキャラクターに加工したもの。元ファイルに付いていた Meshy の自動リグ(24 ボーン、指・顎なし)とそのアニメーションは使わず、下記の 53 ボーンのリグに作り直している。

## 納品物

| ファイル | 内容 |
|---|---|
| `Oliver_Cowboy_Tears_A_Pose_rigged.blend` | 編集用 Blender 4.5 ファイル(リグ・ウェイト・シェイプキー・チェック用アニメ入り。テクスチャは `textures/` を相対パスで参照) |
| `Oliver_Cowboy_Tears_A_Pose.fbx` | FBX(ボーン・ウェイト・口のブレンドシェイプ・チェックアニメ。テクスチャは `textures/` を相対パスで参照、ベースカラー+ノーマル) |
| `Oliver_Cowboy_Tears_A_Pose.glb` | glTF Binary(スキン・モーフターゲット・アニメ。テクスチャ埋め込み、ベースカラーは JPEG q92 に再エンコード) |
| `textures/` | `base_color`(4096²) / `normal`(4096²)(元データに roughness / metallic のマップは無い。マテリアルは roughness 0.6 / metallic 0 の固定値) |
| `Oliver_Cowboy_Tears_A_Pose_check.mp4` | 動作確認動画(手を開く→握る→開く / 指1本ずつ / 人差し指・ピース / 口の開閉 / あいうえお / 笑顔→通常) |

モデルは A ポーズ(腕・胴・脚が離れた状態)で開く。キャラクターは **-Y 方向を向き、+Z が上**(Blender 座標、1 unit = 1 m)。`Right` はキャラクターの右手(-X 側)。

## ボーン(Mixamo 風の命名、`mixamorig:` 接頭辞なし。全 53 本)

```
Hips
└ Spine ─ Spine1 ─ Spine2
   ├ Neck ─ Head ─ Jaw                         (Jaw = 下顎。口を開く)
   ├ LeftShoulder ─ LeftArm ─ LeftForeArm ─ LeftHand
   │    └ LeftHand{Index|Middle|Ring|Pinky}{1,2,3}   (各指3関節)
   │    └ LeftHandThumb{1,2,3}
   ├ RightShoulder ─ RightArm ─ RightForeArm ─ RightHand
   │    └ RightHand{Index|Middle|Ring|Pinky}{1,2,3}
   │    └ RightHandThumb{1,2,3}
   ├ LeftUpLeg ─ LeftLeg ─ LeftFoot ─ LeftToeBase
   └ RightUpLeg ─ RightLeg ─ RightFoot ─ RightToeBase
```

* 指は左右とも**5本独立**(親指 + 人差し指/中指/薬指/小指 × 各3関節)。
* **指の曲げ**: 各指ボーンを**ローカル X 軸まわりに回転**(正の角度 = 手のひら側へ曲がる)。回転モードは Quaternion。握りの目安は MCP/PIP/DIP で約 80° / 100° / 60°。
* **親指**は対向(オポジション)を含むため単純な X 回転では握れない。`tools/oliver_rig/rig_poses.py` の `thumb_pose(arm, 'R', 0..1)`(最適化で求めた握り姿勢を `Armature["oliver_thumb"]` に保存)か、チェックアニメのキーを使う。`fist(arm, side)` / `point` / `peace` / `finger_pose(arm, side, 'Index', 0..1)` も同ファイル。
* **指の開閉でも袖・胴は動かない**(検証値は下表。袖/上腕の頂点の最大移動量 0.000 mm)。

## 口・表情(シェイプキー。0〜1)

| 名前 | 動き |
|---|---|
| `jawOpen` | 下顎を開く(最大 約13°相当) |
| `mouthClose` | 唇を閉じ合わせる(わずかに開いた顎を封じる。`jawOpen`≲0.12 まで有効) |
| `viseme_A` (あ) | 大きく縦に開く |
| `viseme_I` (い) | 横に引く(口角を外へ)、顎は小さく |
| `viseme_U` (う) | すぼめて前に突き出す(すぼめ+口幅を狭める) |
| `viseme_E` (え) | 中くらい開き + 横に引く |
| `viseme_O` (お) | 丸く開く(すぼめ+前へ) |
| `mouthSmile` | 口角を上げ、頬を持ち上げる(顎は動かない) |

* **口の構造**: 閉じた一枚の表面だった口を、唇のしわ(幾何の谷)に沿って実際に切り開き、上唇・下唇の裏側から奥へ続く口腔(口内壁)、**上下の歯**、**舌**を追加した(黒い板や顔面の引き伸ばしではない)。口を閉じれば元の顔に戻る。
* **Jaw ボーン**でも口を開ける(ローカル X 軸 正回転、最大 約13°)。`jawOpen` キーと同じ動きになるよう作ってあり(平均差 約0.5 mm)、**両方を同時に最大にすると二重に開く**ので、どちらか一方で使うこと。
* 歯と舌は顎にだけ追従し、口をすぼめる音(う・お)では口腔と一緒に横幅を縮める。ひげ・口ひげはテクスチャとして皮膚の一部なので、口まわりでは皮膚と一緒に動く。**口の中心より 50 mm 以上上(鼻・サングラス・髪・帽子)の頂点のシェイプキーによる変位は 最大 0.12 mm(`mouthSmile` による。顎ボーンのウェイトは 0)**。顎の開閉は下あご〜喉の皮膚にも自然に伝わる(ボーン/キーとも)。
* 音声なし。口の動きはキー値で操作する(下記チェックアニメ、またはスライダー/スクリプト)。

## このモデル固有の加工内容

* **指**: 元メッシュ(溶接後 約5.1万頂点)は間引かれていて粗く、指と指がほぼ接していた。手と口まわりだけを**局所的に細分化**(辺長 約5 mm → 約1.2 mm。細分化後 約14万頂点)してから、4本の指軸と指先を推定し、指と指の接触部を指先側から指の長さの約80%までブーリアンで切り離した(付け根側の約20%は水かき状につながったまま)。切り離しで露出した面は単色の肌色にしてある。
* **口の位置**: 口の位置は顔の深度の谷(唇のしわ)を測って決めた(口角 x = -30〜+14 mm)。口まわりも同様に局所細分化している。
* **親指の握り**: 最適化で求めた握り姿勢の指先到達誤差(目標との距離) R: 0.2 mm, L: 0.2 mm。
* **口腔のクリアランス**(口内パーツ頂点から外側の皮膚面までの最小距離。皮膚を突き抜けたら違反):

| パーツ | 最小クリアランス | 違反頂点 |
|---|---|---|
| upper_wall | 2.34 mm | 0 / 920 |
| lower_wall | 2.39 mm | 0 / 900 |
| upper_teeth | 2.94 mm | 0 / 1056 |
| lower_teeth | 5.16 mm | 0 / 1056 |
| tongue | 11.50 mm | 0 / 260 |

## 元データと加工の範囲(作り直し版)

* 元データ: 作り直された Meshy FBX(`Cowboy.fbx`。https://gofile.io/d/tVUQudhH)。メッシュは UV の継ぎ目で頂点が分かれていたため、同じ位置の頂点を溶接して一枚の連続した面にしてから加工した(形状は変えていない)。元の `.fbx` は変更していない。
* **加工した場所**: 手(指の切り離し)と口まわり(唇の開口・口腔・歯・舌)だけ。顔・髪・服・サングラス・帽子の形状と色は元データのまま。
* **サングラスの色**: 元データのテクスチャでサングラスと肌の色が混ざっている部分があるが、依頼により**修正していない(元のまま)**。
* 顔の作り直し(参考写真に合わせた顔の補正)はこの版では行っていない。

## 制約・既知の問題

* スキニングは自動(測地距離ベース + 手指は関節チェーンから明示計算)。**服・髪・帽子・フリンジは肌と同じスキニング**で、布や髪の物理シミュレーションはない(腕を大きく動かすと服の変形は線形ブレンドスキンの限界が出る)。
* 口腔は様式化したもの(単色の口内壁、簡易な超楕円体の歯と舌、舌ボーンなし)。母音の形は近似で、実際の発話の口形をすべて再現するものではない。
* 指の独立した曲げは水かき状につながった部分(癒着していた手の付け根側)を引き伸ばす。ピースサインで2本が離れる量は小さい。
* **元データに roughness / metallic マップが無い**ため、材質は固定値(roughness 0.6 / metallic 0)。FBX / GLB / .blend ともベースカラー+ノーマルのみ。GLB のベースカラーは JPEG(q92)に再エンコードされている。
* **口を閉じるキー `mouthClose`**(唇を強く閉じ合わせる)では、口角に 1〜2 mm の薄い皮膚の折り返し(三角形の小さなはみ出し)が出る。通常の閉じた口は元の顔(キー 0)で、そこには出ない。
* 指を1本だけ曲げると、癒着していた指の間の面(水かき状の部分と切り口)が引き伸ばされ、平らな肌色の「ひれ」状に見えることがある(Cowboy で目立つ)。切り口の面は単色の肌色で、元のテクスチャの質感はない。
* 元のメッシュは三角形のみ・単一メッシュで、頂点法線は(編集後に)自動スムースで再計算されている。
